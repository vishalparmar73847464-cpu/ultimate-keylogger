
#  🎓 ULTIMATE KEYLOGGER v4.1

### Cybersecurity Research Keylogger

A Python-based **cybersecurity research project** created to study keyboard-event monitoring, endpoint activity, system telemetry, and security monitoring techniques in authorized environments.

---

## ⚡ Features

| Module                 | Description                                    |
| ---------------------- | ---------------------------------------------- |
| ⌨️ Keyboard Monitoring | Captures keyboard events for security research |
| 🪟 Window Context      | Associates events with the active window       |
| 📸 Screenshots         | Periodic screen capture functionality          |
| 🎥 Webcam              | Camera capture module                          |
| 📋 Clipboard           | Clipboard activity monitoring                  |
| 💻 System Info         | Host, user, CPU, RAM and runtime information   |
| 📡 Telegram API        | Remote notification/reporting integration      |
| 🧵 Multithreading      | Independent monitoring modules                 |
| 🛡️ Error Isolation    | Module-level exception handling                |

## ⚙️ Configuration

Telegram configuration is defined using placeholders:

```python
TELEGRAM_TOKEN = "PASTE_YOUR_BOT_TOKEN_HERE"
CHAT_ID = "PASTE_YOUR_CHAT_ID_HERE"
```

**Do not commit real API tokens, credentials, or secrets to a public repository.**
